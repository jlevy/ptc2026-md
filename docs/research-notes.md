## Conflicting and Incomplete Sources

The event’s xAI and Netflix affiliation labels conflict with the linked profiles’
Msquare Labs and Oracle labels.
The records preserve each claim with its source; they do not choose an employer or
invent a transition date.

Most collected LinkedIn profiles expose public snippets, with incomplete employment and
education sections. Empty fields mean unknown.
Repository statistics are observations at retrieval time.
A pinned repository establishes an association, but does not establish authorship or
contribution by itself.

Some professional sites were available only in the earlier saved public snapshots.
Those observations remain distinguished from freshly retrieved API records.
The host’s event announcement survives as a public embed; a direct X refresh was
unavailable. Vivek’s project submission links a repository that now returns 404, so the
project link does not establish that the repository is still available.

A public event-promotion post names two additional community-support leads.
It establishes neither their attendance nor a specified event role, so they have not
been added as participants.
The official schedule names sponsor workshops without identifying individual presenters
or mentors. No sponsor’s employees or founders have been added merely because their
organization sponsors a track.

## Collection and Publication

Bright Data supplies public LinkedIn and X profile metadata.
Raw snapshots use allowlists and contact redaction before entering this repository.
Unselected X post bodies, other people’s profile/activity data, personal finance and
immigration entries, contact details, and scraper bookkeeping are excluded.
Selected professional writing and work remain cited in curation.

The build is offline and records sources, schema contracts, account linkage and
biography provenance.
The [build report](build-report.json) gives entity and enrichment counts, and
[contract notes](contracts.md) describe the shared schema additions.
See the [data policy](data-policy.md) before publishing or extending this research.
